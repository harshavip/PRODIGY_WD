How to Play

The rules are simple, but the game needs proper state tracking and winning condition logic.

1

Choose Game Mode

Select Player vs Player to play with a friend or Player vs AI to play against the computer.

2

Take Turns

Player X always starts first. Each player clicks an empty cell to place their marker.

3

Win or Draw

The first player to get three markers in a row wins. If all cells are filled without a winner, it is a draw.

Technologies Used

The application is built using core front-end technologies and runs directly in the browser.

HTML

Structures the navigation, game board, buttons, scoreboard, rules, sections, and footer.

CSS

Styles the website with responsive layouts, hover effects, animations, gradients, and cards.

JavaScript

Handles clicks, player turns, AI moves, game state, win conditions, draws, and score updates.
